# 🛒 Tienda Virtual con JavaScript + Firebase

Una aplicación web sencilla y moderna creada con **HTML**, **CSS** y **JavaScript puro**, que utiliza **Firebase Firestore** como base de datos para almacenar productos y gestionar la tienda en línea.

---

## 🚀 Características principales

- 🧩 Interfaz ligera y responsiva con HTML + CSS.  
- 🔥 Conexión en tiempo real con **Firebase Firestore**.  
- 🛍️ Visualización de productos (nombre, imagen, descripción, precio).  
- ➕ Posibilidad de añadir, listar o actualizar productos desde la base de datos.  
- ☁️ Código 100% basado en el cliente (sin servidor propio).
